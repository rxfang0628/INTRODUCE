# 方法与实现

PCML 的完整前向链路是「共享骨干 → 双分支取证 → 分支对齐 → 像素构造 → 像素判别 → 融合回退」。以下按执行顺序展开。

## 1. 共享骨干

CLIP ViT-L/14-336 全程冻结，不参与任何训练。输入图像统一为 518×518，输出两类中间量：

- **patch token**：取第 6、12、18、24 层的 patch 表示，按通道拼接成 4096 维；
- **语义响应**：经可学习提示与 UAFM 对齐后，逐层得到一个 37×37 的异常响应图，对四层取平均作为语义证据。

骨干选择 6/12/18/24 四层的原因是浅层保留纹理与边缘、深层保留语义与结构，两层之间的互补性在消融中最强。

## 2. 纹理分支：PatchCore 检索

纹理分支不做学习，只做最近邻检索：

| 项 | 取值 | 说明 |
|---|---|---|
| 特征维度 | 4096 | 四层 patch token 拼接 |
| 记忆库 | 目标类正常样本 | 每类独立建库 |
| 子采样 | 随机取 10% | 非贪心 k-Center，成本低但代表性弱于原版 |
| 近邻数 | k = 3 | 距离取前 3 均值 |
| 距离计算 | GPU 分块 `cdist` | 避免 4096 维全量矩阵爆显存 |
| 归一化 | 正常样本距离 p2 / p98 | 全局线性映射，得到 37×37 纹理图 |

## 3. 语义分支

可训练部分只有提示与轻量适配层：`Context_Prompting` 提供类条件提示，`UAFM` 做视觉—文本特征对齐，`LCBlock` 做一次并行后精炼。这部分的权重由源域 VisA 上的提示训练得到，评估时冻结。

## 4. 分支对齐：CBE

CBE（Cross-Branch Enhancer）把两路证据在通道维上互相校准：

- 4096 维纹理特征 → 256；1024 维语义特征 → 256；
- 双向交叉注意力：纹理查语义、语义查纹理，各得到一份增强表示；
- 拼接为 512 维，送入两层 SpatialTransformer 做 37×37 的空间一致性建模。

与简单拼接相比，双向注意力的作用是让「纹理显著但语义平静」和「语义显著但纹理平静」的区域互相唤醒，减少单一分支的漏检。

## 5. 像素特征构造：16 维

| 组 | 维度 | 内容 |
|---|---|---|
| 纹理统计 | 3 | 原始纹理值、3×3 邻域均值、3×3 邻域标准差 |
| 语义统计 | 3 | 同构三项，作用于语义响应图 |
| 跨分支 | 8 | 512 维 CBE 输出 → 128 → 8，逐像素压缩 |
| 位置 | 2 | 归一化行列坐标，补偿不同类别的空间先验差异 |

16 维是刻意压低的结果：维度越高，像素分类器越容易在小样本上过拟合到具体缺陷形状。

## 6. 像素判别：类别感知 MLP

- 输入 784 维 = 16（像素）+ 768（图像级类别上下文）；
- 结构：784→64→32→1，Sigmoid 输出；
- 每个类别各有一个独立 MLP，共 12 个；
- 测试时用图像特征与 12 个类别原型的余弦相似度选类；最高相似度低于 0.8 时，取相似度最高的两个 MLP 按相似度比例插值，缓解跨类误判。

## 7. 融合与回退

两路证据的融合由一个离群守卫控制：

1. 对 16 维像素特征拟合正常样本的均值与协方差，得到平方马氏距离；
2. 距离超阈值的像素记为离群像素；
3. 若离群像素比例超过 0.5，整图回退为固定权重融合 `0.5 × 纹理 + 0.5 × 语义`，绕过 MLP；
4. 否则采用 MLP 输出作为像素分数。

图像级分数由 37×37 = 1369 个 patch 分数中取最高的 100 个求均值（约 7%），再上采样到 518×518 与真值掩膜比对。

## 8. 训练设置

| 项 | 取值 |
|---|---|
| 源域 | VisA，12 类，含真值掩膜 |
| 划分 | 按类 7:3 分为训练/验证 |
| 输入 | 518×518，CenterCrop |
| 可训练参数 | CBE + 像素特征构造 + 类别 MLP（骨干与提示冻结） |
| 优化器 | Adam，lr = 1e-4，weight decay 1e-5 |
| 损失 | 加权二元交叉熵，异常像素权重 pos_weight = 10 |
| 轮次 / 批量 | 10 轮（共享 CBE）/ 30 轮（单类），批量 8–16 |
| 随机种子 | 333 |

## 9. 模块职责对照

| 模块 | 职责 |
|---|---|
| `PatchCore` | 记忆库构建、分块 KNN 检索、p2–p98 归一化 |
| `CBE` | 纹理/语义双向交叉注意力与空间精炼 |
| `PixelFeatureBuilder` | 16 维像素特征拼装 |
| `CategorySpecificMLP` | 类别选择、单类像素判别、top-2 插值 |
| `OODGuard` | 马氏距离离群判定与固定权重回退 |
| `ResidualMLP` | 在固定融合上做残差修正（λ = 0.1，tanh 限幅） |
| `extract_tex_map` | 预计算纹理图并落盘，避免训练期重复检索 |
| `compute_prototypes` | 用正常样本均值构造 768 维类别原型 |

| 件 | 用途 |

| 源域提示训练权重 | 语义分支初始化 |
| CBE / 像素特征的逐类检查点 | 融合头初始化 |

| 预计算纹理图（.npy） | 可重算，也可复用 |
