# PMD—光度立体融合：高反光表面微观缺陷检测

面向消费电子外壳、玻璃盖板、抛光金属件等高反光/镜面表面，融合**相位偏折术（PMD）**与**光度立体（PS）**两种光学测量手段，在**单次 PMD 采集、不增加实体光源**的前提下，同时检出两类物理来源不同的微观缺陷。

## 要解决的问题

光泽表面的在线检测需要同时兼顾两类缺陷：

- **几何型缺陷**：浅划痕、压痕、磕碰、流痕，表现为局部表面起伏与斜率突变；
- **光度型缺陷**：残留指纹、油污、汗渍、灰尘、水印，几乎不改变几何形状，只改变局部反射特性。

常规明场/暗场打光在镜面处容易过曝，且难以同时压住两类缺陷；激光三角测量在纯镜面表面会丢失回波，对无起伏的指纹无响应。

## 两条光学路线及其互补性

| 路线 | 擅长 | 短板 |
|---|---|---|
| **相位偏折术 PMD** | 对镜面斜率突变（几何划痕、压痕）灵敏度高，可解算镜面斜率场 | 漫反射区域条纹信噪比下降；对只改变反射率的指纹几乎不响应 |
| **光度立体 PS** | 擅长漫反射表面的纹理与细微起伏，对指纹、油污等光度型缺陷敏感 | 需实体多方向照明；强镜面像素处高光饱和、法向失真；多光源多采集牺牲节拍 |

PMD 长于几何划痕、弱于漫反射指纹；PS 长于漫反射指纹、弱于镜面高光——二者在反射特性上天然互补。

## 方法思路

传统方案把 PMD 工位与 PS 工位**物理串联**：两套光学硬件、两次定位、两次采集。本项目把这一流程在算法层闭环：仅采集一次 PMD 的 8 张相移图，从 PMD 中间量**自举**出虚拟的 PS 观测，再按逐像素光泽度加权融合两路法线，最终输出缺陷显著图。全程不增加实体光源、相机或二次采集。

- **技术栈**：C++ / Visual Studio 2022（x64）/ OpenCV / Intel TBB / 商用 3D 视觉 SDK（相位偏折 + 光度立体）
- **输出**：浮雕图（Emboss）、法线图、缺陷强度增强图，可对接 AOI 判图流程
