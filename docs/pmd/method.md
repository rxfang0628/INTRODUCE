# 方法流程

整体流程分四个阶段：PMD 相位解码 → 虚拟光度立体渲染 → PS 法线解算 → 光泽加权融合与缺陷增强。

## Stage 1 — PMD 相位解码

输入 8 张相移灰度图（分辨率约 2448×2048），送入 PMD 求解器，输出：

- X/Y 斜率场 `px / py`（取一阶梯度 `s1x / s1y`）；
- 逐像素强度图 `gray`、镜面分量 `spec`、光泽分量 `gloss`、漫反射分量 `diff` 与混合图；
- 以强度图非零区域生成全局掩膜，各结果图按 1%–99% 分位数稳健归一化。

## Stage 2 — 虚拟光度立体渲染

用 PMD 斜率重建局部法线（斜率先做高斯平滑）：

```
N_pmd = (-sx', -sy', 1) / sqrt(sx'² + sy'² + 1)
```

反照率纹理由镜面分量与光泽分量分位数拉伸后等权合成：

```
ρ = 0.5 · S_norm + 0.5 · G_norm
```

在画面四角、高度 `z = 0.4·width` 处放置虚拟点光源，逐像素归一化光源方向 `L_i`，按朗伯模型渲染 4 张虚拟 PS 输入图：

```
Ĩ_i = ρ · ( max(0, N_pmd · L_i) · g_light + a_amb )
```

## Stage 3 — 光度立体法线解算

将 4 张虚拟图与 `4×3` 光照方向矩阵送入 PS 求解器，输出：

- 漫反射法线 `nx / ny / nz`、反照率；
- 积分深度、主曲率（Gauss / Mean）、旋度、散度等派生图。

## Stage 4 — 光泽加权法线融合与缺陷增强

**融合权重**：光泽图 `G` 本身就是天然的"镜面度"权重。分位数归一化后做幂次调制：

```
W = (G − G_min) / (G_max − G_min) 的 γ 次幂，  γ = 2.0
```

镜面区信任 PMD，漫反射区信任 PS。PS 法线分量先经双边滤波保边去噪，再与 PMD 法线做凸组合并重新归一化：

```
N_fused = ( W · N_pmd + (1 − W) · N_ps ) / ‖ W · N_pmd + (1 − W) · N_ps ‖
```

**双路缺陷显著图**：

- **标准 DoG 通道（几何/划痕）**：对阴影信号做高斯差分（micro 高斯减 macro 高斯背景）后线性增益，输出标准浮雕图；
- **软阈值 + CLAHE 通道（低对比指纹/油污）**：对 DoG 残差做软阈值抑制（低于阈值置零、否则整体减去阈值，避免微噪声被放大），再做 CLAHE 自适应直方图均衡；
- **缺陷强度图**：水平法线幅值叠加纹理残差（大尺度高斯背景相减），同时突出划痕与指纹。

## 可调参数

| 参数 | 默认值 | 含义 |
|---|---|---|
| `spike_filter_size` | 5 | 中值滤波去孤立尖峰的核大小 |
| `noise_filter_strength` | 7 | 双边滤波强度（法线图降噪） |
| `gamma_weight` | 2.0 | 光泽融合权重的幂次 |
| `tex_boost` | 3.0 | 纹理残差（指纹）增益 |
| `emboss_gain_std / kernel_std` | 80 / 71 | 标准 DoG 浮雕增益与背景核 |
| `core_thresh` | 0.015 | 高级分支软阈值抑制量 |
| `emboss_gain_adv / kernel_adv` | 150 / 71 | 高级 DoG 增益与核 |
| `clahe_clip_limit` | 3.0 | CLAHE 截断限 |

## 方法局限

- 虚拟 PS 渲染基于朗伯反射假设；强镜面像素上渲染图只是近似，这也是融合时用光泽度对其降权的原因。
- 四个虚拟光源固定在四角，其几何如何随工作距离自适应，留待后续。
- 当前输出为缺陷显著图，与后续缺陷分割/分类网络对接是自然的下一步。
