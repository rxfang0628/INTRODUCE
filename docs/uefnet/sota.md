# 对比实验

## 口径说明

- 对比对象均为**目标评测类无样本**的视觉语言零样本方法，在相同测试集与评价指标下横向对照：WinCLIP、AnomalyCLIP、AdaCLIP、Crane、LOGIC-AD、MuSc-V2、CMGL。
- 表中基线数值取自各自论文在同类协议下的报告值；各方法的骨干、输入分辨率与提示训练方式并不完全一致（WinCLIP 为提示集成，AnomalyCLIP / AdaCLIP 需在提示层训练，MuSc-V2 用无标注样本互打分，LOGIC-AD 依赖逻辑空间一致性，CMGL 为跨模态引导），因此横向对比需结合设定差异解读。
- UEF-Net 一行使用本文统一协议，图像与像素指标均在同一套权重上测得。

## 主要观察

1. **图像级全面领先**：五数据集均值 97.3 / 93.7 / 97.5，高于最强基线 CMGL（95.1 / 93.7 / 96.6）与 MuSc-V2（94.8 / 91.8 / 93.7）。
2. **像素级区域精度提升最大**：均值 Pix AP 64.5 较 MuSc-V2（56.5）高 8.0 个百分点，PRO 95.9 较 CMGL（90.1）高 5.8 个百分点、较 MuSc-V2（87.5）高 8.4。
3. **Pix AUROC 与最强基线基本持平略低**（96.3 vs 96.8）：该指标在强方法上接近饱和，差异主要来自排序细节；Pix AP 与 PRO 的增益说明高分像素更集中于真实缺陷区。
4. **单数据集表现**：MVTec、BTAD、DTD 上 Pix AP 与 PRO 最优；DAGM 的 Pix AUROC 与 VisA 的 Pix AP 仍有优势空间，说明弱掩码与细长机械件仍是难点。
