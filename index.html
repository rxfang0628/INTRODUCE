机器视觉项目集

这里汇总两个工业视觉方向的研究项目：一个面向零样本工业异常检测，一个面向高反光表面的光学测量与微观缺陷检测。

项目

UEF-Net：零样本工业异常检测

面向工业质检的零样本异常检测与缺陷定位方法。以冻结 CLIP 骨干为基础，推理阶段不更新参数、不使用目标类样本，通过多尺度纹理记忆库、冻结语义分支与冲突感知的证据 / 像素门控融合，完成图像级异常判定与像素级缺陷分割。

  • 方向：零样本 / 少样本工业异常检测（ZSAD）
  • 关键模块：多尺度纹理记忆库、证据融合头（CBE）、证据组合（PFB）、像素门控融合（CAPGF）
  • 入口：概览 · 方法架构 · 实验结果 · 消融实验 · SOTA 对比

PMD—光度立体融合：高反光表面微观缺陷检测

针对金属、玻璃、漆面、消费电子外壳等高反光表面，把相位偏折术（PMD）的镜面法线与光度立体（PS）的漫反射法线加权融合，单次 PMD 采集即可同时检出几何划痕与光度指纹，输出可对接 AOI 的浮雕图、法线图与缺陷强度图。

  • 方向：3D 光学测量 / 结构光与偏折术 / 表面缺陷检测
  • 关键流程：PMD 相位解码 → 虚拟 PS 渲染 → PS 法线解算 → 光泽加权融合 → 双路缺陷增强
  • 入口：概览 · 方法流程 · 结果预览
