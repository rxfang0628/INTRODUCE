消融实验

以下消融均为 MVTec AD 15 类均值口径，用于拆解各模块对图像级与像素级指标的贡献。消融中"逐层标准化（avg-norm）"指视觉分支多层响应经 z-score 对齐后等权聚合。

各组件的作用机理并不相同：

  • 基线的图像级判别主要由视觉距离支撑，但未对齐的多尺度响应使高分像素不够集中，区域精度受限（Pix AP 56.3）。
  • 加入 CBE：标量响应被转换为带不确定度的证据并按冲突折扣，改变了原有响应分布。由于尚未接入聚合与门控，对立证据直接参与评分，冲突像素的过度自信使 Pix AP 降至 52.4——这一步提升图像级 F1，却损害了区域精度。
  • 加入 PFB：Dempster 组合与保守异常分改善了分割形态，但缺少门控回退时，高冲突位置仍采纳组合结果、不可靠分支未被排除，区域精度基本原地（52.5）。
  • 加入 CAPGF：精度回升至 58.1。门控在高冲突位置回退等权保守融合，抑制不可靠证据的自信投票与背景假阳性，使高分像素集中于真缺陷区域——这说明门控是证据建模兑现为定位能力的必需环节。
  • 加入逐层标准化：Pix AUROC / Pix AP / PRO 达 96.3 / 64.4 / 97.8，较基线提升 1.5 / 8.1 / 1.0 个百分点。消除不同 Transformer 层距离的量纲差异后，多尺度响应不再被远距离层主导，各层纹理与边缘的贡献被合理利用。

结论：CBE / PFB 提供了可区分正常、异常与不确定的证据表示基础，但其价值必须经门控回退才能兑现；门控解决冲突位置的过度自信，标准化解决多尺度量纲失配，二者与互补双分支共同构成定位增益的来源。

组件与多尺度对齐消融

配置 说明 Img AUROC Pix AUROC Pix AP PRO
baseline 单尺度基线 97.8 94.8 56.3 96.8
avg_raw 四层等权，未标准化 98.6 95.0 60.3 96.9
avg_norm 四层等权 + 逐层 z-score 98.7 95.6 63.2 97.3
no_smooth 去掉门控高斯平滑 97.8 97.0 63.5 97.2
gate_off 关闭门控，退回固定 0.5 等权融合 97.2 91.7 52.0 87.1
UEF-Net 完整模型 98.8 96.3 64.4 97.8

该表把像素级增益分解为两个相互正交的必需组件：

  1. 量纲对齐而非堆层数：从单尺度基线到四层等权（avg_raw），Pix AP 仅提升约 4.0 个百分点，单纯堆叠层数并不能释放多尺度表征；加入逐层 z-score 后升至 63.2，说明对齐不同层距离的量纲是关键。
  2. 门控是核心，而非平滑：去掉高斯平滑（no_smooth）后 Pix AUROC 与 Pix AP 基本不变，表明平滑只影响热力图视觉连续性，不是精度来源；而关闭门控（gate_off）后退回固定 0.5 融合，Pix AUROC / Pix AP / PRO 跌至 91.7 / 52.0 / 87.1，较完整模型下降 4.6 / 12.4 / 10.7 个百分点。

gate_off 的显著掉点直接验证了"双分支不能简单平均"：两路结论对立时固定权重无法区分分支可信度，会把不可靠响应带入决策；像素级冲突门控按分歧程度回退保守融合，才是定位精度的核心来源。层间量纲对齐与门控回退互补而非冗余——前者解决多尺度失配，后者解决冲突位置的过度自信。
