UEF-Net：双分支证据冲突建模与像素门控融合

UEF-Net（Uncertainty-Guided Evidential Fusion Network）是一套面向零样本工业异常检测的融合框架。它在目标评测类别不提供任何正常或异常样本、也没有像素级标注的条件下，同时完成图像级异常判定与像素级缺陷定位；CLIP 骨干全程冻结，只有提示层、特征投影与融合头在外部辅助数据集上学习。

研究背景

工业异常检测的目标是判断工件图像是否存在缺陷，并在存在缺陷时定位其像素区域。传统监督范式需要为每个产品类别采集正常与缺陷样本、逐类训练模型，难以适配小批量、多品类的柔性制造场景。零样本设定把这一负担转移到可迁移的先验上：评测类不参与任何训练或建模，仅借助冻结的跨模态语义先验与在外部辅助数据上学到的提示表示判别未见类别。这一设定在 3C 电子、新能源电池、半导体封测等快速换线的产线上有直接价值——新工件上线时无需采缺陷样本、无需重训模型，即可获得可用的初版检测能力。

现有路线的局限与本文的科学问题

现有方法沿三条路线发展，各自的短板恰好互补，却难以直接结合：

  • 纯视觉嵌入路线（记忆库最近邻、知识蒸馏、自监督建模）：同源场景定位精度高，但跨类别迁移时正常分布先验不足，输出为纯统计距离、缺少语义解释性。
  • 视觉语言路线（CLIP 提示学习）：具备开放语义，跨类别判别强，但像素定位偏粗，热力图依赖浅层特征上采样，对划痕、压痕、纹理错乱等小面积缺陷召回不足。
  • 双路融合路线：多在特征或响应层直接加权平均，只在下游"合并分数"。

问题的关键在最后一条：加权平均仅在两分支判断一致时稳定。当结论相互矛盾（视觉分支可疑、语义分支判正常）时，平均只会得到模糊的中间分数——既不利用冲突本身的信息，也没有可解释的不确定性度量。

本文的科学问题：在目标类无样本、不使用缺陷像素标签的条件下，如何对视觉与语义两路异常证据进行统一建模，显式度量并利用逐像素证据冲突，使模型在证据一致时获得融合增益、在证据冲突时能够稳健回退，而不产生模糊的中间决策。

方法概览

UEF-Net 沿"特征抽取 — 证据建模 — 冲突门控融合"的推理链条逐级处理输入：

  1. 视觉分支：冻结 ViT 第 6/12/18/24 层多尺度补丁特征，经投影后与外部辅助集学到的领域文本原型计算相似度偏差，逐层 z-score 标准化后等权聚合为视觉异常图；不构建面向目标类的正常样本记忆库。
  2. 语义分支：可学习领域提示生成正常、异常及属性文本嵌入，与视觉特征逐位置对齐，输出与视觉图同分辨率的语义异常图。
  3. CBE（跨分支估计器）：把两路异常图编码为正常、异常、不确定三类证据质量，以四维像素级冲突统计驱动自适应折扣。
  4. PFB（证据聚合）：在折扣证据上执行 Dempster 组合，得到融合证据与"异常证据 + 不确定证据加权"的保守异常分。
  5. CAPGF（冲突感知像素门控融合）：逐像素估计门控权重，低冲突区域采纳证据融合结果，高冲突位置回退到视觉与语义等权保守融合，抑制误检的空间扩散。

主要贡献

  1. 统一的双分支证据表示与冲突感知融合框架：两路异常图分别编码为三类证据质量，以像素级冲突驱动折扣与门控，一致时用证据组合、冲突处回退保守融合。
  2. 多尺度视觉特征与领域提示对齐机制：融合 ViT 第 6/12/18/24 层补丁特征，在辅助集上学习领域文本原型与特征投影，消除层间量纲差异；等权融合不引入面向目标类的记忆样本。
  3. CBE 与 PFB 的像素级证据估计与聚合：两个参数独立的证据编码器分别建模两路证据，冲突统计驱动折扣系数；PFB 在无额外参数条件下执行 Dempster 归一化组合并给出保守异常分。
  4. CAPGF 冲突感知像素门控：融合局部与全局两种尺度的冲突统计，经 Sigmoid 门控与高斯空间平滑，在像素粒度混合证据融合与等权融合结果。

当前进展（2026-11-28）

主线数值已定稿，此后开辟的局部学习分支（DINOv3 冻结骨干 + 轻量局部头）完成四轮实验，四轮在目标域均未超过其自身第一版，主线结果不受影响。

局部学习 v1 MVTec 89.2 / 88.5；BTAD 88.6 / 94.6 保留为分支基线
局部学习 v2–v4 全部回退（v2 像素 −2.7 点） 判负归档

同期完成了评测口径重写（AUPRO 改为 FPR ≤ 0.30、4096 级近似；F1/IoU 明确为 oracle 指标），因此本轮数字与 11-26 之前的结果不可直接相减。时间线、四轮明细、协议边界，以及一处尚待统一的零样本口径，见 研究进展。

方法局限与展望

  • 像素热力图建立在 37×37 粗网格上，极低占比的小缺陷受分辨率约束；外观多变的类别图像级判别仍有波动。
  • 后续方向：引入高分辨率分层特征增强小缺陷表征；改进高冲突证据的再分配策略；结合时序一致性扩展到序列工件检测。
